# GradPath

GradPath is a data-driven career and skill-gap analysis platform
designed to help graduates understand the skills required for
target roles and identify gaps between their current profile
and job-market requirements.

## Current Phase

Phase 1 — Knowledge Base

The current phase focuses on building an evidence-based knowledge
base from job-market data, skill taxonomies, learning resources,
and manually labeled CV data.

## Target Roles

- Data Analyst
- Data Scientist
